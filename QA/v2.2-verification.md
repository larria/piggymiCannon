# v2.2.0 AI 排查与验收

日期：2026-11-15。基线5652a0a / v2.1.0；本轮只改AI决策、只读预测与AI行动衔接，不改弹药／伤害、风、地形、命中判定、相对角、天气、库存或四槽位规则。

## 逐项复现与修复

| 用户反馈 | 复现／原因 | 修复与实际结果 |
|---|---|---|
| 多人AI偏弱 | 只求最近敌人的单弹落点，射击评分没有按所有敌人的实际伤害与可达性选目标 | 两种自有武器与可用追踪弹参与评估；评分合并齐射命中、有效伤害、击杀、状态和地形机会。近敌受保护时能选较远且可击中的敌人 |
| 近距不会轻点力度 | 搜索从22起、2°粗角度，且距自身100以内的落点额外加罚；输出偶尔抖到22以下并不等于搜到了低力度解 | 全10～100力度搜索，粗筛后细化到0.25°／0.25力度；取消无条件近距惩罚。仅在实际开启自伤／友伤时计入相关风险 |
| 王牌不会主动走位 | 原来只在火焰或低地面条件下短暂往中心移动 | 比较当前与安全候选位置，计入燃料、时间和移动等待成本。使用正常move逐帧移动，抵达／受阻后重算；长遮挡可先走到本回合可达的安全点，为下一回合打开射线。没有给实际机体额外燃料 |
| 命中不稳定 | 原预测省略追踪转向、交织运动、齐射散布及卫星后续射线，误差和固定抖动叠加 | 只读预测使用同一风／重力常量、碰撞宽限和身体判定，模拟追踪、交织、散布初速及卫星遮挡。保留难度失误与小幅角／力度偏差，近距刻意失手仍朝已知敌方一侧，而非突然转向无人侧；实际炮弹飞行与伤害完全不修改 |

走位路线复用既有安全traversable与move：不主动掉落，保持60°／12px限制、不越过永久支撑、不穿过活人或队友；检查燃料、冻结、地雷与火／毒危险区。只在收益足够或存在可达射击位置时移动，低难度基本原地；雾中继续使用记忆的近似位置。路线被坍塌打断时等待落地后重新瞄准，空中不能移动／射击。

## 命中率口径

以实际fire与damage事件记录一次完整行动。直接命中造成HP／护盾损失，或同一行动内任一敌人损失至少max(30,5%最大生命)，记为有效命中。真实挖地导致的坠落／水面出局可计入；延后毒伤与下一行动的持续伤害不挪到本次。不中、被地形挡住、飞出地图和未击中的正常射击全部保留在分母，双发／齐射仍算一次行动。统计不依据预测分数，不改伤害，也不筛掉难场景。

- 固定单行动语料：240个独立种子／难度，六张真实地图144例＋90／130／220／600距离控制96例，共960次2v2射击。13种载具、自伤／友伤关闭、无雾／火线，风照常作用。最终新兵111/240=46.25%、老兵143/240=59.58%、精英160/240=66.67%、王牌201/240=83.75%。用于检查难度梯度与距离覆盖。
- **主要75%验收：36场完整全AI 2v2对战**，六地图各6个独立种子，四名AI全部王牌，关闭雾／火线，正常库存、状态、挖地和随回合变化的风。443次实际射击，340次有效命中＝**76.7%**，306次直接命中；103次失手、53次行动有真实移动，36场全部正常结束。这组包含被持续改变的地形与后续回合，作为最高难度验收，而非仅用第一炮的较高命中率。
- 中间候选的完整对战只有68.9%，未发版；补齐长遮挡走位、落地重算，并用连续战斗口径校准误差／失手后复验达标。每张地图及各距离分项均保留在JSON，不声称每个地图或每局都固定75%。

最终数据：ai-v2.2-single-action-results.json、ai-v2.2-complete-match-results.json。复现命令npm run test:ai；统计代码在tests/ai-scenarios.ts、tests/ai-benchmark.ts和tests/ai.test.ts，均执行实际战斗。
