# v4.0.0 验收 · 2026-11-17

## 空投先于对应人类行动

保留5次行动检查一次。到了检查点只在存活人类之间等概率选接收者；非对应人类行动时仅建立预定，不生成箱体。在接收者行动前，用当时的风、地形和坐标重新检查可拾取落点，进入原空投跟随／落地观察阶段后才开放人类输入。AI不会在本次下落和接收者行动之间插入一炮。箱体在后续回合仍可被炮击摧毁。

预定目标倒地／改为AI取消，没有安全落点跳过；全AI局不抽人类补给。预定队列、接收者、检查／实际投放行动进入快照。版本分支只作用4.0.0及以后，旧3.2.9／3.2.7录像保留原时机。

96个种子均匀抽取测试覆盖四位人类，各座都有机会；克隆快照后实际箱体与随机状态一致。落地观察仍约0.95秒，整个空投阶段45秒计时不减少，AI火力输入被阶段阻止。原镜头7项回归覆盖远水平落点、上下边界／降落伞、多箱、雾下观察、手动小地图、跟随恢复、暂停、巡展和Canvas降级。旧镜头夹具原先默认第5行动立刻出现箱体、并固定下一位在地图左侧；已改为等待预定接收者，并明确摆放远落点场景，避免把随机接收者位置误当镜头失败。

## 积分／成就／AI边界

四角色各自保存人类积分。青铜0／白银200／黄金600／王者1200，逐档晋级、失分降级、0分下界。胜局+10～60，负局−5～35，按战前自己与敌方平均勋章差调整；组队按队伍胜负，队友不参与对手均值，平局／提前退出／录像不计分。完整公式与取舍见 research/PROGRESSION_4.md。

AI新兵／老兵／精英／王牌严格固定青铜／白银／黄金／王者，即使该角色有高积分人类档案也不采用。无论AI胜负均不加减该角色积分，不计AI战绩或AI成就；它的固定档位仅参与人类加减分。测试覆盖16种对手档位组合、人类对AI／人类、队伍共享胜负但独立分数、跨门槛降级、0分实际扣分、平局、重复结算、AI高人类档案保持、全AI局、清空／损坏／权限拒绝的存储。

14项成就按单份定义驱动描述与目标：人类完赛／胜局／连胜／越阶／敌方实际伤害与击倒／己方实际治疗／拾取／双发强化组合／6图／13载具／王者。只在成功人类动作或完整人类对局结算计数，解锁一次，失分不回收，不额外加积分。

真实浏览器录制回归发现可用性检查被误放入道具计数，导致HUD刷新增加items而回放不增加。修正为仅在consumeItem实际消耗后计数；增加1000次只读查询不得改变统计、失败使用不得计数测试，并对真实界面录像前后完整现场／随机状态比较通过。短流程单元录像和真实界面录像都保留。

存储配额失败时提示“本机存储不可用，积分仅在本次打开期间保留”。保存失败后的后续结算采用内存记录，不被旧存储覆盖；浏览器用例连续两局失败后仍显示2场／60分。积分只写piggy-progression-v1，录像明确不结算，不上传。
