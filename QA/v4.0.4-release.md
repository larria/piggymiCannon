# v4.0.4 验收 · 2026-11-17

## 审核与实现

来源：本机 ft2 目录/原版分析。证据哈希见 research/FT2_DIG_REVIEW_EVIDENCE.json，支持与推断边界见 research/FT2_EXCAVATION_REVIEW.md。

独立复核得到3:2椭圆扫描线和碰撞采样爆点；不采信材料中“命中必定改到敌人中心”的解释。26种载具武器移除正中固定扣深度，实际高低爆点产生不同地形交集。伤害仍用窄中心/入射线与距离衰减；飞火四段伤害、挖掘收尖、永久支撑阻挡保持。尺寸沿用本作半宽校准，原版单位/角色对应没有强套。桥面击穿炮数随新的椭圆半高变化，属于本版明确手感调整。

录像JSON导入/导出：大小、版本、地形编码、实体、操作参数、时长与恢复校验；重复文件去重，同ID不同内容保留副本，存储失败不删旧录像且可直接播放。旧录像保持原版本规则，结束时校验HP、地形、随机状态等摘要。

多发相机使用最大屏幕Y（最低弹）的X/Y；不按可见范围过滤。最低落点保留直到有更低的弹或进入结算，避免最后一发高空弹拉走镜头。延迟未发射弹不参与；手动定位、空投、暂停与巡游规则保留。
