# v2.2.2 单局诊断快照验收

日期2026-11-15，基线44fc8c1 / v2.2.1。AI与黄金导弹已发布，本次在其上只增加可观测性，统一升一个补丁版。

## 设计与可复现边界

- 当前Game对象独享BattleTrace；构造新Game（新对局、再来一局、退出演习场）即创建全新缓冲，没有跨局引用。结算／复制不清除，下一局才替换。无localStorage／sessionStorage／IndexedDB或上传调用，不采集账号、设备、浏览历史或个人信息。
- 设置面板下方小号文字“复制本局快照”，另支持Ctrl／⌘+Shift+L；一次复制中文按时间摘要＋同一事件对象的JSON块。成功轻量toast，API缺失或拒绝时明确提示授权／重试。既有版本号点击与长按提示保持。
- 格式piggy-battle-snapshot／formatVersion=1；事件sequence、time、action、round、actor、type、summary、rngIndex、data固定。开局包含游戏版本、种子、地图、四槽旗色与解析后的载具、操作者／难度、实际天气与规则；回合记录全席HP／护盾／状态／库存、DELAY与风／火线，动作记录移动端点／坡度／燃料、瞄准、道具、齐射每枚弹、锁定／命中／挖地／火线／追加／消散及补给。
- 伤害data记录base、factors、requested、actual、shieldBefore／After、absorbed、hpBefore／After、owner／target、关系／规则、来源武器、公式与挖土。威力加强／火线共享一次1.5，发怒1.5、雪天1.25、实际scale、地雷／衰减及继承boost修正分项列出。暴龙固有武器基础值明确没有凭空追加倍率；挖土与伤害分开。≥最大HP50%的单次计算／扣血标“高伤害”，是观察标记，不直接判定规则错误。
- 致死death保留完整lethal伤害对象及源弹发射／命中信息；坠落／出界保留引发支撑变化的挖土与来源，毒伤保留30%停止线，火烧／毒气／地雷／决胜扣血各自标原因。护盾消除、冻结及道具回血变化有独立事件。
- 缓冲最多1000事件／350KB UTF-8事件数据，移动和瞄准连续或交替操作合并为动作，重大事件会切断合并；不记录每帧坐标。超限移除最旧一般事件，开局独立保留，每局至多4个death及对应4个完整致死damage固定保留；截断计数明确可见。地形仅复制时压缩RLE，极端碎片用位集回退（两层合计约274KB）；正常快照更小。
- mulberry32种子、全调用索引及可恢复state保留；关键抽取记录value／state，粒子随机只累计索引以控制体积，不增减随机调用。Game.fromBattleSnapshot(snapshot)还原当前地形／永久层、全席、弹体、缓存、计时器、AI决策、来源与RNG，支持继续逐步模拟。动画粒子／旧尾迹不恢复；它们不改变战斗。若在设置中复制，paused=true，恢复后先设paused=false。合并事件不是逐帧输入，截断后不承诺从开局逐帧精确重演；现场恢复与后续随机／物理有自动测试。
