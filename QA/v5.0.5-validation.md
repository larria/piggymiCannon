# v5.0.5 验收 · 2026-11-18

## 实现与边界

- 新增「显示蓄力辅助」和「坦克相互阻挡」，两项默认关闭，设置与开局面板共用配置，本机存储／快照／录像包含两项。旧录像仍按旧移动阻挡规则执行；新规则键只能用于5.0.5及以后录像。
- 移动可穿过活体及地图内倒地后的身体；打开阻挡后恢复阻挡，已经重叠时允许朝外分离。炮弹活体／倒地后的身体矩形碰撞、自伤／友伤和卫星子弹地面判定保持；AI路线和实际移动共用阻挡规则。
- 辅助在移动／角度输入结束200ms后开始计算，以0.5%力度步长扫描当前炮口方向；与AI／真实发射共用初速、坡度、风、弹道、追踪、卫星与多发散布。每个敌人独立归一化受击强度，正中最深，偏离渐浅，多人色带可叠加；仅占横条下沿8px，保留原横条蓄力、上次力度填色及上沿手动标记。
- 每批以4ms为预算（一个弹道探测为最小不可分任务），批次之间让出主线程；停稳后缓存、蓄力期间保留结果并暂停计算。继续输入、风／地形／角色／方向／武器／生死改变、弹框／暂停／后台／换局均清理旧任务。色带是当前静止战场的预测，不能保证之后地形破坏或多段／双发改变地形后的后续伤害；不会消耗RNG、改地形／HP／弹药／AI／录像。雾中隐藏敌人不显示；恢复弹／转移弹与指定落点空袭不显示伤害辅助。
- 复现「倒地事件在队伍切换后处理」时，旧处理按新行动角色的队伍把上一位人类的AI队友当作敌人；新倒地事件固定记录当时observerTeam，并保留旧录像fallback。实际地形失去支撑掉出底边的AI队友已覆盖，Friend样本只触发一次。没有用户该次乌龙杀的快照，不能断言所有此类反馈都由这条路径造成。倒地后若立即结算，掌声至少推迟1秒，避免覆盖倒地提示；中途倒地不播放掌声。
