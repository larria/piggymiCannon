# 5.1.8 仪表盘与倒地动画验收

- 检查 1512×982 电脑、1194×834 的 11 寸 iPad 横屏模拟、390×844 手机竖屏和三种手机横屏（844×390、667×375、568×320）。移动键到跳过键的触区之间，竖向间隔为 16 CSS px，手机横屏横向间隔为 14 CSS px。保留原有触区尺寸；手机横屏仪表盘仍高 90 CSS px。最窄横屏下，额外武器、四个道具、瞄准和蓄力控件都通过实际操作回归。
- 用实际战场绘制代码检查四人倒地：哑光布质军装以翻盖口袋、领章和袖口区分；小黄鱼只绘制一套鱼形和尾鳍，保留小领口与胸鳍。阿狸和小黄鱼的尾尖随时间摆动，开启减少动态效果时静止；咪猪头和阿狸仍交替捶地，并且坠落时不会捶地。
- WebKit 16 项、Chromium 10 项通过。检查了电脑、iPad 模拟、手机竖屏、最窄手机横屏与四位炮手的倒地截图。
- 构建 65.16 MB，PWA 预缓存 65.11 MB（163 个独立 URL），参考目录未随页面发布。见[容量记录](v5.1.8-size.json)和[本地离线验收](v5.1.8-local-offline.json)。
