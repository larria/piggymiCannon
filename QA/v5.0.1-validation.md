# 5.0.1 验收 · 2026-11-18

## 速度与比例核查

5.0.0将视口宽从1280扩大到1792，坦克与炮弹绘制补偿了1.4，但运动仍使用原位移。因此相同初速／掉落在屏幕上只有原来的71.43%。此版用本作4.0.5的屏幕速度作为对照，并保留5.0.0已确认的世界2688×1344、物理单位与地图关键尺寸。

- 飞行使用原始速度／重力／风力／弹种路径与小步碰撞，物理轨迹时间按1.4补偿；26种原生弹在等物理时间的位置、初速、倍率完全一致，只更快到达同一轨迹点。见motion-{chromium,webkit}.json与screen-motion.test.ts。
- 坦克／尸体／降落伞／箱子采用位移补偿，原加速度、终端速度参数保留；空投预测与真实落地同步。步行更快通过原距离，仍按原单位扣燃料，移动总距离不增加。AI走位的剩余步长同步，防止过冲。
- 双发间隔0.75秒、固定机体接触飞火分段间隔、蓄力200ms、计时、反应、道具提示和天气展示保持真实时间。移动穿土的飞火仍在原物理间距开坑，未改半径、深度、伤害或多弹分布。旧版通过版本门保留原节奏。
- 降落伞／箱体／道具提示／风向颗粒／爆炸粒子的装饰比例补偿；箱体绕落地底边缩放。物理盒、拾取范围和爆炸／挖土尺寸不扩大。原小地图、暂停缓存、巡游与弹着观察逻辑保留。
