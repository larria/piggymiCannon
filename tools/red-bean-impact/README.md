# 小红豆受击临时测试页

运行 `npm run dev`，访问 `/tools/red-bean-impact/`。不接入游戏主入口、不注册 PWA、不发布、不更改机制。

`standalone.html` 是约 55KB 的离线单文件，内嵌当前诊断代码、绘制代码和本次数据，可以直接用浏览器打开。它是此次临时产物；主入口仍为使用游戏模块的 `index.html` / `main.ts`。

数据来自用户提供的 v4.0.5 钢铁工厂快照，种子 3959126173：第 13 行动的第 16、17 弹，事件 413 / 422，伤害事件 417 / 426。受击者阿狸驾驶雷霆，站位 (828, 780)，倾角 −0.38588266939807375 弧度，两发均 325 伤害。截取了第 13 行动开头的角色状态；这两发间其站位和永久支撑未变。

页面复用游戏 `paintVehicle` / `paintCrew` 外观，`sourceDamagePoint` / `sourceDistance` / `sourceFalloff` / `sourceDamage` 与 `pointHitsTank` / `preciseContact` 判定。绿色满伤格使用实际 3 单位源网格取整规则，不把日志中用于说明的名义半径画成实际命中区域。

永久层只从快照中不变的 protectedMask 截取。未重建命中时全部可挖地形，不能用保存时的地形反推当时弹坑。两爆点差约 0.000067 世界单位，用外环标识第 17 弹而不人为移动爆点。点击探索只是“假设这里爆炸”的数值对比，不代表真实轨迹能穿过机体。

游戏生产构建只有根 index.html 入口，这个 tools 页面不在 dist / PWA 中。

验收：TypeScript 检查通过；两发接触点位于旋转矩形 localX=30 边界，游戏函数均返回机体接触、非正中、2/3 距离系数、325 伤害；假设爆点设为参照点时为满伤 488。1194×834、DPR2、触屏浏览器截图已逐张查看，标注与模型无遮挡。浏览器按钮点击验证遇到控制上下文失效，未将其记为通过。

后续原客户端与实机图复核见 [复核报告](../../research/FT2_RED_BEAN_REFERENCE_REVIEW.md)。当前页面展示的是本作的旋转矩形（OBB），原代码用轴对齐AABB；本作的旋转参照与0.8系别折扣也不应被当作原式。`reference-review/` 保存原客户端代码摘录、数字测量与两张分别标注的截图。用户已校正旧体感：垂直正中两发普通弹不穿独木桥中段。
