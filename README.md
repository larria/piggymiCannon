# 咪猪头的疯狂坦克 · v1.5.0

以小猪为炮手的回合制炮术 PWA，支持单人挑战 AI 和双人热座。TypeScript、Vite 与 Canvas 2D 实现，不需要账号或后端。

[在线开战](https://larria.github.io/piggymiCannon/)

## 运行与发布

```sh
npm install
npm run dev           # http://localhost:4175
npm test              # 战斗机制、坦克与完整对局回归
npm run build:pages   # 类型检查，构建 /piggymiCannon/ 子路径
npm run preview:pages # http://localhost:4177/piggymiCannon/
npm run test:browser  # Chrome，11 英寸 iPad Pro 横屏、触控与离线回归
npm run deploy        # 自动构建，再用 gh-pages 发布 dist/
```

源码使用 `main`，GitHub Pages 使用 `gh-pages` 根目录和 `.nojekyll`。普通静态托管可使用 `npm run build` 和 `npm run preview`（4176）。

## 经典坦克与武器

12 款常规坦克：大碗、叉叉、老土、甲壳虫、公爵、雷霆、飞火、流星、小妖、水鬼、闪灵、海怪；另有隐藏款暴龙。每种坦克独占普通／特殊两武器，拥有独立生命、仰角范围、初速、移动力和行动等待。26 种武器都有不同的炮弹图形与合成音效。

进入对局可分别为两位队长选坦克，首次默认随机，之后记住选择。随机有 10% 概率抽到暴龙，其余概率由 12 款常规坦克均分；不能手选隐藏款。普通与特殊武器在仪表盘直接切换，特殊武器增加下一次行动的等待。等待影响行动顺序，轻快坦克可能提前再次行动。

老土的大铅弹低伤、宽范围、强挖地，小红豆高伤、小范围、弱挖地；其他武器包括毒箭、漂移毒气、双地雷、四段穿甲、末段追踪、三／九发齐射、螺旋能量弹、冻结移动和卫星打击。海怪半血以下增强炮火。追魂弹与九发黄金导弹在末段追踪最近机体，不识别敌我，也会误锁自身或残骸；空投猎星追踪弹仍为敌方索敌，有锁定圈、追踪线和连续索敌声，仍受地形阻挡。

名称与核心行为依据公开经典资料核对；地图尺度、伤害、射程、移动换算和隐藏款数值按 Web 对战校准，不宣称原客户端所有版本的精确复刻。来源、完整映射与平衡取舍见 [资料核对](research/FORTRESS2_WEAPON_AUDIT.md)。

## 操作与仪表盘

- 小款 iPad Pro 横屏：充满视口的战场，上方双方头像／生命，战场底部中央小地图，下方紧凑仪表盘。验收尺寸为 **1194×834** 和 **1210×834**，对应不同代 11 英寸款。
- 拖动圆形角度盘或战场瞄准；角度受坦克范围限制，左右可换炮口朝向。长按箭头前进／后退，方向相对炮口，后退不会改变瞄准方向。
- 按住红色力度条或开火按钮蓄力，从 10% 起步，2.5 秒到 100%，松手发射。白线记住上次力度。**没有预测弹道**；拖动发射键不再改变角度，可用另一只手同时调整角度盘。
- 绿色能量条显示生命，黄色移动力条显示剩余移动预算。每次自己的回合恢复全部移动力。前进／后退、两武器、快捷道具和跳过／退出采用大触控按钮。
- 四个直接使用的道具位为维修、护盾、燃料、强化；其他道具从军火库取用。不可用时禁用并说明条件。
- 点小地图可查看对应高度，点「跟随」恢复自动镜头；可折叠小地图。飞弹与空投仍自动跟镜。
- 键盘：←→ / A D 移动，↑↓ / W S 角度，空格蓄力、松开发射，F3 / F4 双武器，F5 跳过，F9–F12 四道具，Tab 小地图，Ctrl+C 镜头跟随，Esc 暂停。
- 暂停、取消触摸、切换窗口或回合结束会取消蓄力，避免误发射。双人热座每次交接都需下一位队长确认。

## 战场与规则

- 青苔峡谷有高地与中央断崖，独木桥有可挖穿薄桥，天空之城有低重力、多层浮岛。地形是二维像素占用，支持洞穴、桥下空洞与下层平台。
- 超过 35° 的坡面、断桥、空洞和敌人会阻挡移动；车身贴合地面，炮口按世界角度瞄准。坠落超过 48 米会受伤，掉到水面立即出局。
- 每类炮弹独立配置挖地宽度／深度。落地挖地为基础半径 1.35 倍、深度 1.5 倍；直接命中更集中，挖地较小。可以通过破坏支撑击落满血对手。
- 炮弹飞行以 1.8 倍时间速度播放，物理路径与射程保持一致，计时按真实时间。
- 风每回合变化，落叶或飘雪直接显示风向、风力。浓雾与火线分别以 1/30 概率出现；浓雾隐藏敌人及生命，AI 依据上次听到的近似位置行动；火线使穿过的炮弹伤害 +50%，单枚不重复叠加。
- 默认 AI 为新兵，开局可选新兵／老兵／精英／王牌。所有级别有瞄准误差和主动失手，高难度会用道具、特殊炮火和挖地策略；王牌仍保留 16% 主动偏离概率。
- 计时可选 30／45／60 秒或不限时。时间耗尽交出回合；暂停与对话框停止计时。第 21 轮进入决胜阶段，风增强，每次行动损失最大生命的 8%。
- 双方头像为咪猪头与大猪头爸爸，可点击放大，再戳戳有轻摇、爱心与俏皮回应。低于 1/3 生命时喘气；正中、擦伤和摔伤有不同哭泣／皱眉／晕眩动画。
- 设置、坦克选择与战绩保存在当前设备；不保存中途对局。

## 道具与空投

7 种道具：维修包、能量护盾、燃料补给、火力强化、战术转移、定风装置、双发装填。每回合限一件，不消耗射击机会，还受战术点、库存、冷却、解锁回合和条件限制。初始 2 战术点，每次自己的回合恢复 1，上限 4。

维修恢复约 23% 最大生命并解毒，需生命不高于约 77%，消耗 2 点；护盾约为最大生命的 27%，不能叠加，消耗 2 点；燃料 +55，需剩余不高于 45%，消耗 1 点；强化 +50% 伤害，第 2 个自己的回合解锁，消耗 3 点；传送第 3 个自己的回合解锁，消耗 3 点，落点在 230 米内稳定平台；双发只从空投获得，消耗 3 点，只用于当回合。

每 5 个行动回合安排一次补给。落点经过风偏、边界、稳定平台、坡度连通与咪猪头两回合移动预算检查。带降落伞受风漂移，镜头跟随并播放落地声；空投整个动画阶段不扣回合计时。落地后靠近拾取，可得到回血、双发或稀有猎星追踪弹。

## PWA 与版本更新

支持安装到主屏幕、横屏独立窗口与离线运行。iPad Safari 用「分享 → 添加到主屏幕」；支持安装提示的平台有安装按钮。首次联网完成缓存后，游戏、字体、音乐、音效与头像可离线使用。

版本号来自 `package.json`。演习场页脚与全屏战场右下角的版本号可点击检查更新，`version.json` 不进入缓存，检查强制访问网络。新版本在演习场或结算时提供更新按钮，不在交战中强制刷新；离线或失败会明确提示。发布前更新 package 与 lock 的版本，再推送源码、执行 `npm run deploy`。

## 结构与素材

- `src/engine.ts`、`terrain.ts`：物理、二维地形、战斗状态、AI 与行动顺序。
- `src/vehicles.ts`、`catalog.ts`：坦克／武器与道具参数；`vehicle-art.ts`：13 种车体图标；`projectile-art.ts`：39 个不同颜色／轮廓的弹体。
- `src/renderer.ts`、`dashboard.ts`：战场、表情、镜头、角度盘、小地图与粒子。
- `src/main.ts`、`guide.ts`：配置、操控、对话框、热座、战绩与指南。
- `src/audio.ts`：音乐、点击、移动／蓄力／追踪循环与每武器炮火合成。
- `tests/`：59 项规则回归与浏览器对局、触控、安装／离线测试；`QA/`：实际浏览器截图。

音乐与点击／庆祝声来自用户提供的 `piggymicharacter3/public/audio/`，坦克发射、爆炸、蓄力、履带、索敌与落地声由 Web Audio 合成；有效点击位置统一有音效反馈。默认总音量 65%，可在设置调整，保留静音选择。图标原图保存在 `assets/app-icon-source.png`，爸爸原图保存在 `assets/dad-avatar-source.png`。

战场、坦克、炮弹与界面均为原生 Canvas／SVG 绘制，没有使用原版游戏美术。字体为 DM Sans、Manrope 与系统中文字体。

## v1.4 原版武器核对

本轮读取并对照了 2006 年 Blue Forever 玩家攻略、日文原文角色表和中文武器名称表，未获得原客户端完整数据；全部 26 行的弹数、效果、证据强度、修正和待确证参数见 [逐武器核对表](research/FORTRESS2_WEAPON_AUDIT.md)。军火库明确显示伤害、半径与挖地数值为本作配置，不再用续作 FAQ 来确证原版。

火焰／毒气改为按模拟秒结算，暂停、热座交接与空投阶段不额外扣血。毒箭每次全场行动交接结算，耐毒型减半，海怪半血时停止，其余型号红血时停止。紫冻水采用本作的正中触发，定身两个自己的回合；原资料与续作的回合数差异已标注。

开局可选真实飘雪，会灭火、散毒、显示伏雷，并给水鬼本作的 +25% 增伤。旧版玩家资料有 +25%／+50% 的冲突，未声称其中一个是所有原版的官方值。弹体图鉴展示当前可用的 26 种坦克弹和 1 种空投弹，所有 39 个定义都有唯一颜色与轮廓。

## v1.5 紧凑控制与移动

对局顶部状态栏为 56px，下方仪表盘约 140px。在 1194×834 视口中，战场由 469px 增至 614px，不需要滚动页面。小地图位于战场下方中央。

短点武器／道具／功能图标执行操作，长按约 420ms 显示名称和说明，松手不会触发操作。禁用道具也可查看原因。移动仍为长按箭头，开火仍为长按蓄力、松手发射，角度盘仍可拖动，不会被说明手势覆盖。轻点头像仍可看大图，长按头像查看状态。

移动采样会识别脚下同一块平台的真实表面，跨过不超过 12 个世界像素的小台阶。持续坡面仍保留 35° 保护，并容忍像素取整误差；40°／45°／55° 持续坡、大立面、断桥仍会阻挡。越台阶是短小地形的特例，未取消坡度限制。
