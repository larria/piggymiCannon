# 咪猪头的疯狂坦克 · Mimi's Crazy Tanks

一个以小猪坦克为主角的完整回合制炮术 Web 游戏。使用 TypeScript、Vite 与 Canvas 2D，战斗逻辑与绘制分离，不需要账号或后端。

在线游戏：https://larria.github.io/piggymiCannon/

## 运行

```sh
npm install
npm run dev
```

打开 http://localhost:4175 。点击「进入战场」，选择模式、战场、AI 难度与回合时长。

```sh
npm test        # 战斗规则与完整对局测试
npm run build  # 类型检查与生产构建
npm run preview
```

生产构建位于 `dist/`，可部署至任何静态网站服务。预览地址为 http://localhost:4176 。

## PWA 与 GitHub Pages

```sh
npm run build:pages   # 使用 /piggymiCannon/ 子路径构建
npm run preview:pages # http://localhost:4177/piggymiCannon/
npm run test:browser  # 使用本机 Google Chrome，验证 iPad 触控布局、对局与离线缓存
npm run deploy       # 自动先构建，再用 gh-pages 发布 dist/ 至 gh-pages 分支
```

GitHub Pages 使用 `gh-pages` 分支的根目录，包含 `.nojekyll`。源代码在 `main` 分支。

支持安装到主屏幕、横屏独立窗口和离线运行。Chrome 等支持的平台提供安装按钮；iPad 在 Safari 中点击「分享 → 添加到主屏幕」。首次联网打开并完成缓存后，游戏、音效、字体与图标都可离线使用。版本号来自 package.json。演习场页脚与全屏战场右下角的版本号都可点击检查更新；version.json 不进入离线缓存，检查请求强制访问网络。新版本在演习场或结算页面提供更新按钮，不在交战中强制刷新。离线或检查失败会明确提示，不能误报最新。发布新版本前使用 `npm version patch --no-git-tag-version` 更新版本号，再执行 `npm run deploy`。

应用图标由用户提供的 `5ae7c9a5-579f-4919-8efd-d708c2f44f64.png` 生成，原图保存在 `assets/app-icon-source.png`。

## 玩法

- 单人对抗 AI，或双人热座。热座每回合显示交接确认。
- 双方初始生命 150、燃料 100，每次行动轮流移动、按条件使用一件道具并发射一次。生命低于 50 时，角色有起伏喘气、张嘴呼气和汗滴动画；直接命中后哭泣流泪，擦伤时眯眼皱嘴，摔伤时压缩身体、晕眼和转星。头像分别复用 app icon 和用户提供的大猪头爸爸图片；头像已加大，可点击看高清大图，再戳一戳触发轻摇、小爱心和俏皮回应。大图查看暂停对局计时，关闭后继续。
- A / D 长按后退 / 前进（相对炮口朝向，后退不改变瞄准方向）；W / S 调整角度；长按空格蓄力，松开发射；Esc 暂停。
- iPad 横屏采用大尺寸触控布局：拖动战场或瞄准区调整角度与朝向；按住发射键蓄力，松手开火。也可在蓄力时上下拖动微调、左右拖动转向。支持一手瞄准、一手蓄力的多点触控。
- 蓄力从 10% 起步，2.5 秒达到 100%，之后保持满蓄力。中断手势、暂停、切换窗口或回合结束都会取消蓄力，避免误发射。
- 进入对局自动使用充满视口的沉浸布局，军火库通过右上角按钮展开。支持切换回标准布局；浏览器支持时可点击全屏按钮隐藏浏览器界面。
- 点击战场可以调整瞄准方向；空中支援点击指定落点；战术转移点击 230 米内的地面。
- 燃料限制移动距离，每次自己的回合恢复 18。冰冻时移动耗油加倍，超过 35° 的坡面、断桥、空洞和敌人会阻挡移动；坠落中不能移动或使用道具。
- 炮弹以 1.8 倍时间速度播放，保留原弹道和射程，回合计时仍按真实时间。
- 风力每回合变化，会改变炮弹和空投弹道，落叶或飘雪直接表现方向与强弱。每场分别以 1/30 概率出现浓雾或火线；浓雾中敌方坦克与血量隐藏，AI 只能估计上次听到的位置，仍可听到立体声的移动与炮火。炮弹穿越火线时伤害 +50%，单枚弹不会重复叠加。青苔峡谷提供高地掩护与中央断崖；独木桥由可挖穿的薄桥连接；天空之城有多层浮岛与低重力，可挖掉支撑击落敌人，也可以落到下层平台。
- 地形采用二维像素占用，真正支持桥下空洞、洞穴和多层平台；不再只是高度曲线。超过 48 米的坠落有伤害，失去平台后掉到水面会立即出局。
- 每 5 个玩家回合安排补给箱；落地位置经过风偏预测、地图边界、稳定支撑、坡度连通与两回合燃料预算验证，放在咪猪头能走到的地方。箱子从上方带降落伞落下，受风推动，镜头跟随并播放落地声，整个空投阶段不扣回合计时。落地后靠近拾取，可获得回血、双发、弹药或稀有追踪弹。第 21 轮进入决胜阶段，风力增加，当前坦克每回合受到 12 点伤害。
- 默认 AI 为新兵。新兵、老兵、精英、王牌都具有随机瞄准误差与失手概率；王牌仍有 16% 的主动偏离机会，并非每发必中。高级 AI 会考虑挖穿薄桥和浮岛，但不绕过道具限制。
- 计时可选 30 / 45 / 60 秒或不限时。时间耗尽自动交出回合，打开对话框与手动暂停会停止模拟与计时。
- 设置与完成对局的战绩保存在当前设备的 localStorage；不保存中途对局。

## 武器与道具

13 种武器：标准榴弹、重磅炸弹、三连齐射、散花弹、钻地弹、跳跳弹、火焰南瓜、冰霜炮弹、电磁脉冲、空中支援、大地震、穿甲飞镖、猎星追踪弹。猎星追踪弹仅从空投获得，下降到地面附近时追踪 140 米内的敌人，仍受地形阻挡。除标准榴弹外，均有弹药限制。伤害、爆炸半径、挖地宽度和深度在军火库中可见。13 种炮弹有独立的挖地参数：直接命中集中伤害、挖地较小；击中地形时挖地宽度为基础值的 1.35 倍，深度为 1.5 倍。钻地弹偏纵向，大地震偏大面积，电磁、冰霜与飞镖挖地较弱。

7 种道具：维修包（+35 生命 / 2 战术点）、能量护盾（+40 护盾 / 2 点）、燃料补给（+55 燃料 / 1 点）、火力强化（本回合攻击 +50% 伤害 / 3 点）、战术转移（3 点）、定风装置（2 点）、双发装填（3 点，仅空投获得，本次攻击追加一轮齐射）。每回合只能使用一件，不消耗发射机会；同时受战术点、冷却、库存、解锁回合和使用条件限制。初始 2 战术点，自己的后续回合恢复 1 点，上限 4。维修需生命 ≤115，燃料需燃料 ≤45，护盾不能叠加；强化第 2 个自己的回合解锁，传送第 3 回合解锁。

## 结构

- `src/engine.ts`：可独立运行的地形、物理、碰撞、伤害、状态、AI 与回合状态机。
- `src/terrain.ts`：二维地形占用、桥梁 / 浮岛、椭圆挖地与薄片塌落。
- `src/renderer.ts`：手绘战场、小猪坦克、弹道、镜头跟随与粒子效果。
- `src/catalog.ts`：武器、道具、地图、难度数据。
- `src/main.ts`：操作面板、配置、热座交接、结算、战绩与键盘 / 触屏事件。
- `src/audio.ts`：背景音乐、本地素材音效、Web Audio 炮火合成。
- `tests/engine.test.ts`：规则回归测试与完整自动对局测试。
- `tests/strategy.test.ts`：平台击落、坡度阻挡、武器挖地、道具约束、AI 失手、版本与低血量反馈。
- `tests/interaction.test.ts`：蓄力与拖动瞄准规则。
- `tests/browser/game.spec.ts`：iPad 横屏、蓄力发射、AI / 热座交接与 PWA 离线测试。
- `QA/`：实际浏览器检查截图。

## 素材

背景音乐与点击、庆祝音效从用户提供的 `/Users/larkin_1/Downloads/piggymicharacter3/public/audio/` 复制至 `public/audio/`。发射、爆炸和道具声音通过 Web Audio 合成。音乐默认开启（保留用户之前的静音选择），在用户点击进入战场后播放。默认音量提高到 65%；蓄力使用持续升调音效，发射和爆炸采用冲击噪声、低频与限幅混音。加入履带 / 引擎循环声，移动结束后停止；浓雾中的移动、道具、炮火与落地声根据位置左右定位。可以从设置调节音量。

所有战场、坦克、武器与界面图形均以 Canvas / SVG 原生绘制。字体采用 DM Sans、Manrope 与系统中文字体。
