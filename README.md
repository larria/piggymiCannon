# 咪猪头的疯狂坦克 · v3.2.1

以四位原创炮手为主角的回合制炮术 PWA，使用四个固定槽位自由安排上场、队旗、人类或 AI，支持两队合作对抗及三队／四队混战。TypeScript、Vite、PixiJS 保留场景与 Canvas 连续动画实现，不需要账号或后端。

[在线开战](https://larria.github.io/piggymiCannon/)

## 运行与发布

```sh
npm install
npm run dev           # http://localhost:4175
npm test              # 战斗机制、坦克与完整对局回归
npm run test:ai       # 近距／走位、960次射击与36场完整AI对战统计
npm run build:pages   # 类型检查，构建 /piggymiCannon/ 子路径
npm run check:size    # 检查 dist 与 PWA 预缓存均不超过 90MB；构建时自动执行
npm run preview:pages # http://localhost:4177/piggymiCannon/
npm run test:browser  # Chrome，11 英寸 iPad Pro 横屏、触控与离线回归
npm run deploy        # 自动构建，再用 gh-pages 发布 dist/
```

源码使用 `main`，GitHub Pages 使用 `gh-pages` 根目录和 `.nojekyll`。普通静态托管可使用 `npm run build` 和 `npm run preview`（4176）。

## 槽位、队旗与交接

四个固定槽位绑定咪猪头、大猪头、阿狸和小黄鱼，分别选择上场／空位、A暖桃／B青苔／C晴空／D麦穗队旗、人类／AI及各AI难度。默认只有咪猪头（人类、A旗）和大猪头（AI、B旗）上场；至少两位炮手和两面不同队旗，最多四位。关闭的槽位不生成机体、不占回合、不出现在血条和小地图上，编组只由槽位决定。

地图选择支持“随机地图”：从六张当前可用地图等概率抽取，使用本局种子可复现；战场名称、预览／小地图、天气／重力与配乐显示实际地图。再来一局保留随机偏好并换新种子重新抽取，快照记录实际地图及抽取事件。指定地图保持原种子流程。

已开局的种子在本次页面会话内防重，即使同毫秒或系统时钟重复，再来一局也使用新的32位种子；不通过排除上一张地图来偏置抽取，连续两局仍可能合法抽中同一张。调整槽位与战场后沿用新选择，指定图保持指定图，随机图保持随机偏好。

同旗即同队，不同旗互为对手。旗帜有不同形状和字母，战场机体上方用头像代替名字，圆框、血条、小地图、回合提示及仪表盘配色随队旗变化。人类席位通过仪表盘换色、箭头和镜头轻移交接，无需弹框确认。组队局两队交替，队内存活成员每完整轮各行动一次；纯人类组队的DELAY用于队内选人，单人对抗热座保留全局DELAY排序；只剩一个存活队伍时获胜。自伤和友伤默认关闭，可分别打开；摔伤、底边出界与决胜规则不受攻击开关影响。设置保存在当前设备，旧模式预设升级为默认两席，其他声音与战场设置保留。

咪猪头有红帽蝴蝶结、麦黄围巾与轻快动作；大猪头是宽体、蓝帽马甲与胡子，使用独立的慢速姿态和单臂庆祝。四位角色均有独立头像、战场形象、受击／状态及胜败动作。

## 经典坦克与武器

12 款常规坦克：大腕、叉叉、老土、甲壳虫、公爵、雷霆、飞火、流星、小妖、水鬼、闪灵、海怪；另有隐藏款暴龙。每种坦克独占普通／特殊两武器，拥有独立生命、仰角范围、初速、移动力和行动等待。26 种武器都有不同的炮弹图形与合成音效。13 台本体按下载的原版角色图核对主色与标志结构后独立重绘，飞火为用户确认的红头导弹；车辆选择、图鉴、血条图标、小地图与战场共享几何。原图仅供research内部对照，不进入构建；来源与侧视简化边界见 [逐车设定](research/VEHICLE_DESIGN.md)。

进入对局可为每个席位分别选坦克和 AI 难度，首次默认随机，之后记住选择。随机有 10% 概率抽到暴龙，其余概率由 12 款常规坦克均分；默认不能直接选隐藏款，设置「允许直接选择暴龙」开启后可直接选；这个开关不改变随机的 10%。普通与特殊武器在仪表盘直接切换，同局选择跨回合保留。DELAY仅在纯人类热座启用；单人对抗允许低等待一方连续行动，组队则交替队伍并在队内按等待选人。AI / 混合组队也轮换队伍。

老土的大铅弹低伤、宽范围、强挖地，小红豆高伤、小范围、弱挖地；其他武器包括毒箭、漂移毒气、双地雷、四段穿甲、末段追踪、三／九发齐射、螺旋能量弹、冻结移动和卫星打击。海怪半血以下增强炮火。追魂弹与九发黄金导弹在末段追踪最近的存活可攻击机体，索敌遵守自伤／友伤开关；黄金导弹九枚独立追踪、落点略分散，目标死亡或不可攻击时立即消散同轮剩余弹（含双发追加），保留最后一击并正常结算。空投猎星追踪弹为敌方索敌，有锁定圈、追踪线和连续索敌声，仍受地形阻挡。

名称与核心行为依据公开经典资料核对；地图尺度、伤害、射程、移动换算和隐藏款数值按 Web 对战校准，不宣称原客户端所有版本的精确复刻。来源、完整映射与平衡取舍见 [资料核对](research/FORTRESS2_WEAPON_AUDIT.md)。

## 操作与仪表盘

- 小款 iPad Pro 横屏：充满视口的战场，上方双方头像／生命，战场底部中央小地图，下方紧凑仪表盘。验收尺寸为 **1194×834** 和 **1210×834**，对应不同代 11 英寸款。
- 拖动圆形角度盘或战场瞄准；角度受坦克范围限制，左右可换炮口朝向。长按箭头向左／向右移动，车身与炮口自动转向行驶方向，仰角保持不变。
- 按住红色力度条或开火按钮蓄力，从 10% 起步，2.5秒到100%即自动发射，松手可提前发射。白线记住本局上次力度，结束及下一局清空。**没有预测弹道**；拖动发射键不再改变角度，可用另一只手同时调整角度盘。
- 绿色能量条显示生命，黄色移动力条显示剩余移动预算。每次自己的回合恢复全部移动力。前进／后退、两武器、快捷道具和跳过／退出采用大触控按钮。
- 四个快捷道具为双发、转移弹、威力加强、补给；每局开局各带一件，用掉不会在下一回合恢复；每回合最多使用一件。转移弹装填后按角度和力度发射，随实际落点传送。
- 点小地图可查看对应高度，点「跟随」恢复自动镜头；可折叠小地图。飞弹与空投仍自动跟镜。
- 键盘：←→ / A D 移动，↑↓ / W S 角度，空格蓄力、松开发射，F3 / F4 双武器，F5 跳过，F9–F12 依次为双发／转移弹／威力加强／补给，Tab 小地图，Ctrl+C 镜头跟随，Esc 暂停。
- 暂停、取消触摸、切换窗口或回合结束会取消蓄力，避免误发射。人类席位交接无需弹框确认。

## 战场与规则

- 地图实际边界1920×960，可拖动战场／小地图定位，轻点头像聚焦、长按看大图；开场镜头巡游无遮罩并冻结战斗操作，轮到谁就平滑居中（边缘限制）。坦克、炮弹和爆炸大小不变，Z坡224／48／20px、蘑菇节点及4px薄轨保持既有尺寸，普通地层按用户炮击手感校准：180像素独木桥单发普通弹挖去约54%、两发穿；工厂上层小红豆两发穿；天空上层普通弹一发穿。
- 六张地图：青苔峡谷、独木桥、天空之城薄雪浮岛与中央70%四像素S枝层、钢铁工厂连续Z形永久斜面与可破钢梁、神圣殿堂永久圆顶蘑菇节点与易碎薄轨、古老埃及主题重绘。可在底层斜面／伞盖移位调整车身与射角，保持60°／12px和主动掉落。关键特征、来源和未确证布局见[地图与DELAY核对](research/CLASSIC_MAPS_DELAY_REFERENCE.md)，选图时可展开说明。地形是二维像素占用，支持洞穴、桥下空洞与下层平台。
- 60°以内的合理坡面可以攀爬；持续超过60°的极陡坡、大立面、向上的大台阶和其他载具会阻挡移动；断桥、空洞允许主动驶出后连续下落；车身贴地，相对车身角经统一换算成为绝对水平角。坠落伤害默认关闭，可在设置开启；开启后超过48像素沿用既有摔伤公式，地图没有水面死亡线，只有真正掉穿960像素底边才出局。
- 每类炮弹独立配置挖地宽度／深度。落地挖地为基础半径 1.35 倍、深度 1.5 倍；直接命中更集中，挖地较小。可以通过破坏支撑击落满血对手。
- 炮弹飞行以 1.8 倍时间速度播放，物理路径与射程保持一致，计时按真实时间。
- 风对普通弹道的横向作用为v1.5的3倍，物理与内部AI预测同步。落叶或飘雪直接显示风向、风力。浓雾与火线各有1/30概率；浓雾最多两个行动回合，雾中隐藏敌方位置，**血条和数值正常显示**；AI依据听到的近似位置行动。火线最多两个行动回合，穿越后伤害+50%，与道具加强共用同一标记，绝不叠加；两者均有临时星星尾迹。
- 风向／风力显示在小地图下方的纯图形窄框：白底中心竖线表示无风，淡黄色面积从中心向左／右增长，端线表示当前强度，没有可见文字／箭头／数值；小地图折叠后仍保留窄条。每1–2个完整轮次变化一次，单次最大变化为全风程60%（满东风最多变为20%西风）；风对弹道的物理作用保持。
- 仅现代系自带最多6点／24px、1px细线／最高16%不透明度的弱尾迹，其他系不记录或绘制普通尾迹；所有fireBoosted强化弹只绘制星星；不再绘制金色强化光环。弹体保留形状／颜色，移除少量脱离弹体的速度短线，以细深色边缘提升背景对比。小红豆、旧榴弹及部分细箭／离子弹只在绘图中放大，真实scale、碰撞、伤害、齐射与追踪规则保持。
- 默认 AI 为新兵，每个 AI 席位开局分别可选新兵／老兵／精英／王牌。所有级别有瞄准误差和主动失手，高难度会用道具、特殊炮火和挖地策略；王牌会评估安全射击位置，必要时主动移动并重新瞄准；在六地图完整全AI 2v2验收中有效命中79.3%，仍有可观察失手。统计口径见 [AI验收](QA/v2.2-verification.md)。
- 计时可选 30／45／60 秒或不限时。时间耗尽交出回合；暂停与对话框停止计时。第 21 轮进入决胜阶段，风增强，每次行动损失最大生命的 8%。
- 所有坦克在30%最大生命及以下为红血。海怪不喘气，低于50%时改为发怒、伤害+50%；其他坦克红血时明显起伏喘气。正中、擦伤和摔伤的动作与表情各不相同。四名角色（咪猪头、大猪头、红狐狸阿狸、金黄小黄鱼）均可点击头像放大和戳戳互动。咪猪头与大猪头的头像使用用户提供的原图，槽位、血条、大头像和小地图同步。
- 叉叉毒箭命中未红血目标时中毒，造成伤害的擦中与爆炸波及也计入。目标每完成一次自己的行动，扣最大生命20%，最多扣至30%临界线并停止，不会由毒伤直接致死；补给只回血，不会解除中毒。这是用户指定的本作规则。
- 结束后先播放三秒胜负动画，再显示不遮挡双方的结算卡片。陆地败方只剩趴地哭泣的炮手，落出地图则不留残骸；胜方举手跳跃庆祝。
- 多人对局里陆地角色死亡当回合就显示趴地哭泣；姿态固定，之后炮弹经过、爆炸与脚下挖土不移走它，也不让它挡弹。掉穿底边／出界或没有陆地落点仍不留残骸，活体的下落／摔伤规则保持。
- 设置、坦克选择与战绩保存在当前设备；不保存中途对局。

## 系别相克

按本作归一化规则，古代→未来→现代→近代→古代的优势炮弹满额，其余普通系打八折；超代系出击对普通系满额，受到炮弹八折。原官网转载提供优势方向、原客户端提供属性耐性证据，完整25组合数值为本作适配，不宣称原版精确百分比。每次爆炸按各目标分别计算，日志同时列出系别、火线／强化唯一1.5、发怒、雪天与护盾；坠落、百分比毒伤和火烧／毒气持续保持原规则。依据与表见 [系别核对](research/ERA_DAMAGE_REFERENCE.md)。

神圣殿堂永久蘑菇各部分缩至原尺寸约1/3（伞盖宽48～69px），其余仍4px可破薄轨；站在小弧面能微移调角，驶出有效支撑仍会下落。

## 触屏近射

触屏轻点开火按钮或力度条会立即以最小10%近射；继续按住则平滑蓄力，长按、SPACE与满额自动发射保持。低力度段同时用于玩家、预测和AI，22%以上中远段沿用原速度；贴身名字牌会自动错层，便于辨认队旗字色。

## 把异常现场交给 Codex

在对局或结算后打开“游戏设置”，点击右下角小字“复制本局快照”，将整段内容粘贴给 Codex。也可按 Ctrl／⌘+Shift+L。内容包含中文时间线和同源 JSON，记录伤害倍率、护盾、死亡原因、开局种子、四槽配置、随机状态及压缩现场地形。剪贴板不可用时会提示授权后重试。

记录只在当前Game的内存里，不写本地存储、不上传；结算和复制后保留，重新部署、再来一局或回演习场会新建并清空。事件上限1000条／350KB，连续移动与瞄准合并；截断提示明确，开局与完整致死明细始终保留。“高伤害”标记指单次计算／扣血达到角色最大HP50%，用于观察，未改变伤害规则。

排查时在相同游戏版本源码中用 `Game.fromBattleSnapshot(snapshot)` 还原当前现场，随后调用 `update(dt)` 逐步继续；设置中复制的快照需先设 `paused=false`。地形、弹体、状态时钟与随机状态恢复，动画粒子／旧尾迹省略。合并后的事件不是逐帧输入；截断后不保证从开局逐帧重演。格式与验收见 [QA/v2.2.2-verification.md](QA/v2.2.2-verification.md)。

## 保存与播放对局录像

在设置、战斗记录或结算后点「保存本局录像」，再从主界面「对局录像」选择播放。保存截至点击时的对局；想留完整一局，结算后再保存。同一局再次保存会更新原条目。支持暂停、1×／2×、重播、拖拽查看、头像定位和删除，回放不会修改战绩或开局偏好。

录像格式1复用开局快照并补充精确模拟步进、未合并的操作及蓄力声音提示；可以从开局重放地形、炮击、状态、掉落与道具动画，结束时校验随机数和现场状态。它不受诊断时间线截断影响。只在主动保存后写入本机localStorage、不上传，最多6局，总字符串≤2,000,000字符；空间或权限不足明确提示，不自动删除旧录像。清除浏览器数据会删除录像，跨游戏版本可能出现规则偏差，播放结束会显示校验结果。

飞火普通弹最多四段；永久层会挡住剩余弹段，在接触处逐段爆炸，可破坏地形仍继续穿透。伤害按本作100%／80%／60%／40%递减，分别再计算系别、距离、强化与护盾，快照列出各段系数。原版精确递减比例未确证，见 [v3.2.2验收](QA/v3.2.2-review.md)。

## 弹着性能与 Safari 测试日志

v3.2.3按真实炮坑范围重画地形和装饰，仅上传变化纹理块；保持原DPR、粒子和声音。不限时录制的精确步进使用紧凑内存块，上限保护和旧录像格式保持。回放中复制的快照注明原局、播放器版本及进度，来自当前播放现场。

需要反馈偶发停顿时运行 `npm run dev`，用 Safari 打开 `http://localhost:4175/?impact-profile=1`。打几发后选择设置里的「复制本局快照」，其中会附带弹着各阶段耗时、下一帧间隔、像素／纹理字节和资源数量；控制台也有 `[impact-profile]` 记录。仅开发构建启用，内存最多保留128次，不上传。测量条件、长期挂机对照和截图见 [v3.2.3验收](QA/v3.2.3-review.md)。

## 道具与空投

v3.2.4空投镜头同时跟随箱子的横向与纵向位置，保留完整降落伞；入镜后下落，落地展示约一秒再回到角色。手动定位优先，“跟随”返回供给；3.2.3及更早录像保留原时序并继续校验。详见 [空投镜头验收](QA/v3.2.4-review.md)。

标准回合携带四件道具，双方仅在每局开局各携带一件，使用后保持空槽，不会自动补齐，不额外收取战术点或跨回合冷却。**每回合最多使用一件**，防止道具任意叠加。

- 双发：本次攻击追加一轮同样的炮火，算一次行动，跳过失效。
- 转移弹：先装填，再用原角度盘／力度条发射独立弹体；落点有效时传送过去，不造成爆炸伤害。没有230米点击范围限制，落点在场外、掉穿底边或紧贴敌人则失败，仍消耗本次行动。可再次点击取消装填，未发射不消耗。
- 威力加强：本次攻击伤害+50%，跳过失效。
- 补给：恢复约23%最大生命，不超过上限，不解除中毒；满血时不可使用。

每 5 个行动回合安排一次补给。落点经过风偏、边界、稳定平台、坡度连通与咪猪头两回合移动预算检查。带降落伞受风漂移，镜头跟随并播放落地声；空投整个动画阶段不扣回合计时。落地后靠近拾取，只有对应空槽才能收下；满槽时箱子保留，无回血、补充或覆盖效果。道具补給只存入空槽，需主动使用；稀有追踪弹使用独立弹药格，最多一枚。

## PWA 与版本更新

支持安装到主屏幕、横屏独立窗口与离线运行。iPad Safari 用「分享 → 添加到主屏幕」；支持安装提示的平台有安装按钮。首次联网完成缓存后，游戏、字体、音乐、音效与头像可离线使用。

版本号来自 `package.json`。演习场页脚与全屏战场右下角的版本号可点击检查更新，`version.json` 不进入缓存，检查强制访问网络。新版本在演习场或结算时提供更新按钮，不在交战中强制刷新；离线或失败会明确提示。发布前更新 package 与 lock 的版本，再推送源码、执行 `npm run deploy`。

3.x 后备源素材暂不接入或提交；`.workbuddy/` 与三个 FT2 来源目录继续忽略。最终产物与PWA预缓存硬上限为90,000,000字节，构建／部署前自动检查，选材与性能约束见 [3.x备料规则](research/FT2_3X_ASSET_POLICY.md)。

- `src/audio.ts`、`audio-catalog.ts`：实际地图配乐、十三载具炮火／移动采样及合成蓄力／追踪、独立开关与暂停。
- `tests/`：204项规则回归与浏览器对局、触控、状态动画、独立音频、安装／离线测试；`QA/`：实际浏览器截图。

音乐与炮火等采样来自用户本机 `ft2逆向/resources/sound/` 提取素材，仅用于本项目，未宣称官方授权。六图、大厅、选坦克界面与结算分别配乐；十三载具各有普通／特殊发射与爆炸、移动／停止采样，并接入回合、风／天气、锁定、补给、死亡与UI提示。保留合成蓄力、轻量履带和追踪声。九首BGM保留原曲完整时长，仅用128kbps立体声压缩；100个运行时MP3共约29.15MiB，所选原件压缩约63.78%；来源249MiB素材留在本机并忽略。经典地图依据原客户端MapUtil的允许曲目列表择一：独木桥Stage4、天空Stage9、工厂Stage5、殿堂Stage10、埃及Stage15；原创峡谷保留自选Stage0。[选材与来源](research/FT2_AUDIO.md)附原客户端IL／RVA证据、选曲边界、ffmpeg参数、重建／质量脚本和哈希清单。

设置有独立的**游戏音效／背景音乐**开关，支持任一开启、另一关闭，保存在当前设备；旧总开关迁移为两个相同状态。默认音量65%，暂停／恢复保留播放位置，Safari／iOS在首次手势后解锁。首次缓存后音频全部可离线使用，对局中可从暂停面板进入声音设置。

战场、13台坦克、炮弹轮廓与界面沿用本作 Canvas／SVG 自绘。精选7组用户本机提取的爆破／能量／水花／火焰／毒气及机身纹理，经裁帧、暖色处理与PNG无损压缩后共约285KiB；机身原长喷焰裁掉，仅在现有弹体内部绘纹理，系别弱尾迹／强化星星保持。51MiB原图包留本机忽略，精选图支持PWA离线，参数与来源见 [战斗图材](research/FT2_VISUAL_ASSETS.md)。未宣称官方授权；字体为 DM Sans、Manrope 与系统中文字体。

## v1.4 原版武器核对

本轮读取并对照了 2006 年 Blue Forever 玩家攻略、日文原文角色表和中文武器名称表，未获得原客户端完整数据；全部 26 行的弹数、效果、证据强度、修正和待确证参数见 [逐武器核对表](research/FORTRESS2_WEAPON_AUDIT.md)。军火库明确显示伤害、半径与挖地数值为本作配置，不再用续作 FAQ 来确证原版。

火焰／毒气改为按模拟秒结算，暂停、热座交接与空投阶段不额外扣血。毒箭每次全场行动交接结算，耐毒型减半，海怪半血时停止，其余型号红血时停止。v1.4当时采用正中触发、定身两个自己的回合；v1.6按用户要求改为受到该弹伤害的敌人下一次行动无法移动，自己不会被定身。原资料回合数争议仍保留，不把用户规则当成原版确证。

开局可选真实飘雪，会灭火、散毒、显示伏雷，并给水鬼本作的 +25% 增伤。旧版玩家资料有 +25%／+50% 的冲突，未声称其中一个是所有原版的官方值。弹体图鉴展示当前可用的 26 种坦克弹和 1 种空投弹，所有 39 个定义都有唯一颜色与轮廓。

## v1.5 紧凑控制与移动

对局顶部状态栏为 56px，下方仪表盘约 140px。在 1194×834 视口中，战场由 469px 增至 614px，不需要滚动页面。小地图位于战场下方中央。

短点武器／道具／功能图标执行操作，长按约 420ms 显示名称和说明，松手不会触发操作。禁用道具也可查看原因。移动仍为长按箭头，开火仍为长按蓄力、松手发射，角度盘仍可拖动，不会被说明手势覆盖。轻点头像仍可看大图，长按头像查看状态。

移动采样会识别脚下同一块平台的真实表面，跨过不超过 12 个世界像素的小台阶。持续坡面仍保留 35° 保护，并容忍像素取整误差；40°／45°／55° 持续坡、大立面、断桥仍会阻挡。越台阶是短小地形的特例，未取消坡度限制。

## v1.8 操作、配给与部署

蓄满100%即自动发射，松手仍可提前发射；一轮长按只触发一次。力度参考仅属于本局，结束和新局清空。iOS防干扰覆盖可控的菜单、选字、拖图及缩放，游戏自身长按与双指瞄准／蓄力保留，设置／军火库可单指滚动。

老土两种炮弹是不同大小／颜色的球体且无拖尾。流星、暴龙全部武器略分散，黄金导弹九枚仍独立追踪。正中时挖土向脚下附近投影，卫星正中满额挖宽浅坑；不可破地面仍保持保护。新增数值均为按用户要求调整的Web参数，没有宣称原客户端统一公式。

四道具仅开局各一件，**不会下一回合自动恢复**；满槽不能收同类箱，也不会覆盖。补给箱保留在地面供空槽时拾取，医疗箱不会自动回血。稀有弹药使用独立的一枚弹药格。

出生点随机且保持至少120世界单位间距，优先能双向离开的平台；约22%尝试120–280的近距，其余通常较远。特殊地形可能没有安全近距组合，此时安全优先。60°内的合理坡和斜薄平台可以行驶，65°／70°／80°、断层和大台阶仍阻挡。结算面板自选空白位置，避免随机出生后遮住人物。

流星普通／特殊弹以不同横向和纵向初速度分散，常用角度不会全部重叠；逆风高抛仍可自然收束。直接命中中央核心保留满伤，边缘接触逐渐衰减，爆心满伤范围为18世界像素；挖土与状态的命中实体不缩小。双发第二轮间隔0.75模拟秒，在同一行动内结算。

## 头像加载恢复

头像原图失效时，游戏优先显示已验证的小头像，未有备份时显示内置角色头像。联网、回到前台或缓存安装完成后会尝试恢复原图；也可在设置中点「修复头像」，不必刷新或退出对局，不会清除录像和设置。复制本局快照附带头像加载诊断，便于反馈。备份仅保存在项目自己的CacheStorage，最多八张64px小图；详见 [v3.2.5验收](QA/v3.2.5-review.md)。
